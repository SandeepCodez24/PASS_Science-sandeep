Variables, functions and classes in Neural Code

Neural Code is the language you write in Astra. This guide explains, in plain words, how to store values, how to write your own functions, and how to group data and behaviour into classes. Every example on this page was run, and the output shown is what you will see.

shapes.nc
class Shape():
   function base(w, h=1, label="shape"):
      base.w = w;
      base.h = h;
      base.label = label;
   fnend
   function A = area(scale=1):
      A = base.w * base.h * scale;
   fnend
csend

s = Shape(2, 3);
publish("area =", s.area(), "  area(scale=10) =", s.area(scale=10))
Command Window
area = 6   area(scale=10) = 60

In those few lines there is a class (Shape), an object made from it (s), inputs with default values (h=1, scale=1) and a value passed by name (scale=10). The rest of this page takes each of these one at a time.

Basics

Writing your first lines

A Neural Code file ends in .nc. You write one statement per line and run the file with Run, or type the same lines in the Command Window.

  • End a statement with ; to run it quietly. Leave the ; off and Astra shows the result in the Command Window.
  • publish(...) prints one or more values on a line, separated by spaces.
  • A line starting with # is a comment. It is there for people and is not run.
  • Blocks end with a closing word on its own line: fnend ends a function, csend a class, iend an if, fend a for loop and wend a while loop. Every block header ends with :.
  • Indent by 3 spaces for each level inside a block.

Variables

A variable is a name that holds a value. You create one by writing the name, =, and the value. Writing to the same name again replaces the old value.

variables.nc
# numbers, text, true/false and a fixed-width integer
speed = 12.5;
name = "Astra";
ready = true;
count = int32(7);
publish(speed, name, ready, count)
speed = 20
Command Window
12.5 Astra true 7

speed =
    20

The last line has no ;, so Astra shows the new value of speed.

What kind of value a variable holds

You do not declare a type. The value decides it:

You writeKind of value
x = 12.5;A number. Every plain number is a float64 unless you ask for something else.
n = int32(7);A whole number of a fixed size. Also int8 … int64, uint8 … uint64, and float32 and friends.
ok = true;A bool: true or false.
s = "car"; or s = 'car';A string (text). Either quote works, and one can sit inside the other: "the country 'India'".
A = [1, 2, 3; 4, 5, 6];A matrix. Commas separate values, ; separates rows, and every row has the same length.
z = 3 + 4i;A complex number.
d = dict();A dict: values stored under keys, read with d["key"].

Names

A name starts with a letter or _ and continues with letters, digits and _. Letters from other scripts work too, so μ, α and Indian-script names are fine. A subscript is written _$ and a superscript _@: A_$1 is A with subscript 1, and B_@2 is B with superscript 2.

names.nc
μ = 2.5;
A_$1 = 3;
B_@2 = 9;
publish(μ, A_$1, B_@2)
Command Window
2.5 3 9

Functions

What a function is

A function is a named piece of work you can run again and again. You give it inputs, it does its work, and it hands back outputs. Write it once, then call it by name wherever you need it.

A function starts with the word function and ends with fnend. The header names the outputs, the function and its inputs, and ends with :. Inside, you give each output a value.

functions.nc
# one output
function y = square(x):
   y = x * x;
fnend

# no inputs and no outputs
function hello():
   publish("Hello from Neural Code")
fnend

# two outputs, written in square brackets
function [q, r] = divide(a, b):
   q = a // b;
   r = a % b;
fnend

s = square(6);
publish("square(6) =", s)
hello();
[q, r] = divide(17, 5);
publish("17 divided by 5:", q, "remainder", r)
Command Window
square(6) = 36
Hello from Neural Code
17 divided by 5: 3 remainder 2
HeaderMeans
function y = f(x):One output, y
function [a, b] = f(x):Several outputs. Collect them with [a, b] = f(x);
function f(x):No output; the function only does something, like printing
function f():No inputs

Variables made inside a function belong to that function. They do not change, or even see, the variables of the code that called it.

Default values

An input can have a default value: the value it takes when the call leaves it out. Write it in the header as name = value.

defaults.nc
function greet(name, greeting="Hello", times=1):
   publish(greeting, name, "x", times)
fnend

greet("Siva");
greet("Siva", "Vanakkam");
greet("Siva", "Namaste", 3);
Command Window
Hello Siva x 1
Vanakkam Siva x 1
Namaste Siva x 3

A few things to know about defaults:

  • An input without a default must always be given. greet() is an error, because name has no default.
  • A default can be any expression: a number, text, true, a matrix, or a calculation.
  • A default can use another input. In area(w, h=w), leaving out h makes it equal to w.
  • The default is worked out every time the function is called, not once when it is defined.
defaults.nc
function y = area(w, h=w):
   y = w * h;
fnend

publish("area(4) =", area(4), "  area(4, 2) =", area(4, 2))
Command Window
area(4) = 16   area(4, 2) = 8

Naming values in a call

When you call a function you can give a value by the input's name, written name = value. Named values can come in any order, so you do not have to remember the order of the inputs.

named.nc
function C = Add(x1, x2):
   C = x1 + x2;
fnend

C = Add(x1=10, x2=15);
publish("Add(x1=10, x2=15) =", C)
C = Add(x2=15, x1=10);
publish("Add(x2=15, x1=10) =", C)
Command Window
Add(x1=10, x2=15) = 25
Add(x2=15, x1=10) = 25

Mixing named and plain values

You can mix both kinds in one call, in any order, even putting plain values after named ones. Neural Code fills the inputs in two steps:

  1. Named values go first, each to the input with its name.
  2. Then the plain values, in the order you wrote them, fill the inputs that are still empty, from left to right.

Any input still empty after that takes its default. If it has no default, the call is an error.

Take F(A1, A2, A3, A4, A5) and the call F(A2=10, A4=15, 1, 2, 3). First A2 and A4 are filled by name. The three plain values then go to the inputs left empty, A1, A3 and A5. Try it below: change the call or the header and watch where each value lands.

named in the callplain valuedefault from the header
    mixing.nc
    function F(A1, A2, A3, A4, A5):
   publish("A1 =", A1, " A2 =", A2, " A3 =", A3, " A4 =", A4, " A5 =", A5)
fnend

F(A2=10, A4=15, 1, 2, 3);
F(1, A3=5, 2, 3, 4);
F(10, 20, A1=5, 30, 40);
    Command Window
    A1 = 1  A2 = 10  A3 = 2  A4 = 15  A5 = 3
A1 = 1  A2 = 2  A3 = 5  A4 = 3  A5 = 4
A1 = 5  A2 = 10  A3 = 20  A4 = 30  A5 = 40

    Different from Python. In Python, every plain value must come before the named ones. Neural Code lets you write plain values anywhere. A plain value written before a name does not claim that position: in F(10, 20, A1=5, 30, 40), 10 goes to A2 because A1 was already given by name.

    Defaults and names work well together. Give only the values you want to change, by name, and let the rest take their defaults:

    mixing.nc
    function y = G(a, b=100, c=1000):
   y = a + b + c;
fnend

publish("G(1) =", G(1))
publish("G(1, c=0) =", G(1, c=0))
publish("G(c=0, a=5) =", G(c=0, a=5))
    Command Window
    G(1) = 1101
G(1, c=0) = 101
G(c=0, a=5) = 105

    Named values work for every function and class you write yourself. The built-in functions such as sqrt take their values in order only. Write == when you mean a comparison: f(x == 1) passes one true/false value, while f(x = 1) passes 1 to the input x.

    Several versions of a function

    You can define the same function name more than once, as long as each version has a different number of inputs. Neural Code picks the version that fits the call. Defining a version with the same number of inputs again replaces the old one.

    versions.nc
    function y = combine(a):
   y = a;
fnend
function y = combine(a, b):
   y = a + b;
fnend

publish(combine(4), combine(4, 5))
    Command Window
    4 9

    When defaults mean more than one version could take a call, Neural Code uses the one that needs the fewest defaults. With P(a) and P(a, b=2), the call P(9) runs P(a), while P(9, 9) runs P(a, b=2).

    Passing a function around

    Write @ before a function's name to refer to the function itself rather than call it. Store it in a variable or hand it to another function, then run it with feval.

    refs.nc
    function y = twice(x):
   y = 2 * x;
fnend

f = @twice;
publish(feval(f, 21))
    Command Window
    42

    When a call is wrong

    If a call does not fit the function, Neural Code says what is wrong and shows the function's header, so you can see what it expects.

    mistakes.nc
    function y = G(a, b=100, c=1000):
   y = a + b + c;
fnend

r = G();
r = G(1, 2, 3, 4);
r = G(d=1);
r = G(a=1, a=2);
r = sqrt(x=4);
    Command Window
    Error: function 'G': input 'a' was not given and has no default value (defined as y = G(a, b=100, c=1000))
Error: function 'G': it takes 3 inputs, but 4 values were given (defined as y = G(a, b=100, c=1000))
Error: function 'G': there is no input named 'd' - its inputs are a, b, c (defined as y = G(a, b=100, c=1000))
Error: function 'G': input 'a' is given more than once (defined as y = G(a, b=100, c=1000))
Error: 'sqrt' is not a function or class defined in this script, so its values cannot be named - give them in order

    Mistakes in a header are caught too. An input listed twice, f(a, a), and a default with no value, f(a, b=), are both errors.

    Classes

    What a class is

    A class is a plan for a kind of thing. It says what data the thing holds and what it can do. An object is one actual thing made from that plan. One Shape class can make many shapes, each with its own size.

    The data an object holds are its fields. The functions that belong to a class are its methods.

    A class starts with class Name(): and ends with csend. Inside, the function named base is the constructor: it runs once each time an object is made and sets up the fields. Inside the class, base also stands for the object being worked on, so base.w = w; stores the input w in a field called w.

    shape.nc
    class Shape():
   function base(w, h=1, label="shape"):
      base.w = w;
      base.h = h;
      base.label = label;
   fnend
csend

s = Shape(2, 3);
publish("w =", s.w, " h =", s.h, " label =", s.label)
t = Shape(h=4, 5, label="tile");
publish("t: w =", t.w, " h =", t.h, " label =", t.label)
    Command Window
    w = 2  h = 3  label = shape
t: w = 5  h = 4  label = tile

    You make an object by calling the class by name, Shape(2, 3), which runs its constructor. Read a field with a dot: s.w. Defaults and named values work exactly as they do for functions, so Shape(h=4, 5, label="tile") sets h and label by name and gives the plain 5 to w.

    Methods

    A method is a function written inside the class. Call it on an object with a dot: s.area(). Inside the method, base is that object, so the method can read its fields and change them. A change made by a method stays with the object.

    shape.nc
    class Shape():
   function base(w, h=1, label="shape"):
      base.w = w;
      base.h = h;
      base.label = label;
   fnend
   function A = area(scale=1):
      A = base.w * base.h * scale;
   fnend
   function grow(dw=1, dh=1):
      base.w = base.w + dw;
      base.h = base.h + dh;
   fnend
csend

s = Shape(2, 3);
publish("area =", s.area(), "  area(scale=10) =", s.area(scale=10))
s.grow(dh=5);
publish("after grow(dh=5): w =", s.w, " h =", s.h)
publish(s.lineage())
    Command Window
    area = 6   area(scale=10) = 60
after grow(dh=5): w = 3  h = 8
[init(2, 3),area() -> 6,area(scale=10) -> 60,grow(dh=5)]

    grow(dh=5) changes only h by name and lets dw take its default of 1. Every object also keeps a history of what was done to it, which you can read with .lineage().

    Building on another class

    A class can build on another one. Write the parent's name in the brackets: class Square(Shape):. The new class gets all of the parent's methods, and can add its own or replace them. Inside the new constructor, parent(...) runs the parent's constructor, with defaults and named values as usual.

    This example builds on the Shape class from the section above, so put both in the same file.

    square.nc
    class Square(Shape):
   function base(side=2):
      parent(side, h=side, label="square");
   fnend
csend

q = Square(side=7);
publish(q.label, "area =", q.area())
    Command Window
    square area = 49

    Square never wrote an area method; it uses the one from Shape. If a class writes a method with the same name and the same number of inputs as its parent, its own version is used instead.

    Private and protected fields

    Sometimes a field should only be changed by the class's own methods. List it after private to keep code outside the class from reading or writing it. Use protected instead when classes built on this one should still have access.

    account.nc
    class Account():
   private balance;
   function base(owner, balance=0):
      base.owner = owner;
      base.balance = balance;
   fnend
   function deposit(amount):
      base.balance = base.balance + amount;
   fnend
   function b = show():
      b = base.balance;
   fnend
csend

a = Account("Siva", 100);
a.deposit(50);
publish("balance =", a.show())
x = a.balance;
    Command Window
    balance = 150
Error: field 'balance' is private in class 'Account'

    Abstract and reversible classes

    An abstract class is a plan that is never used on its own. It lists methods that every class built on it must write. Mark it abstract class, and leave those methods with no body.

    A reversible class remembers each state of its objects, so you can step back with .rewind(n).

    special.nc
    abstract class Animal():
   function s = speak():
   fnend
csend

class Dog(Animal):
   function base(name):
      base.name = name;
   fnend
   function s = speak():
      s = "woof";
   fnend
csend

d = Dog("Rex");
publish(d.name, "says", d.speak())
a = Animal();

reversible class Counter():
   function base():
      base.n = 0;
   fnend
   function inc(k=1):
      base.n = base.n + k;
   fnend
csend

c = Counter();
c.inc();
c.inc(k=5);
publish("n =", c.n, c.lineage())
c = c.rewind(1);
publish("after rewind(1): n =", c.n)
    Command Window
    Rex says woof
Error: cannot instantiate abstract class 'Animal'
n = 6 [init(),inc(),inc(k=5)]
after rewind(1): n = 1

    Looking inside a class: .base and .info

    Every class comes with two built-in ways to look inside it.

    You writeYou get
    Shape.baseThe fields the constructor sets up, and what kind of value each one holds. any means it depends on what you pass in.
    FF.base (an object)The object's fields with their actual values.
    Shape.infoEvery function you can call on the class: the constructor and methods, including those from a parent class, with their inputs, defaults and outputs.
    FF.infoThe same as Shape.info, for the object's class.
    inspect.nc
    class Shape():
   private secret;
   function base(w, h=1, label="shape"):
      base.w = w;
      base.h = h;
      base.label = label;
      base.secret = 42;
   fnend
   function A = area(scale=1):
      A = base.w * base.h * scale;
   fnend
   function grow(dw=1, dh=1):
      base.w = base.w + dw;
   fnend
csend

Shape.base
FF = Shape(2, 3);
FF.base
Shape.info
    Command Window
    ans =
    {w: any, h: float64, label: string}

ans =
    {w: 2, h: 3, label: shape}

Shape.info =

    class Shape - 3 functions

    kind          call                           outputs   from
    constructor   Shape(w, h=1, label="shape")   -         Shape
    method        area(scale=1)                  A         Shape
    method        grow(dw=1, dh=1)               -         Shape

    Some details:

    • The private field secret is not listed, because the code asking is outside the class. Inside the class's own methods it is included.
    • Shape.info on its own line prints a table. Store it, I = Shape.info;, and you get a dict you can read from, such as I["count"].
    • base and info are reserved after a dot, so a field cannot be called base or info, and a class cannot have a method called info.
