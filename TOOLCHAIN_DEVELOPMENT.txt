------------------------------------------------------------------------------
 0. BEFORE YOU COPY
------------------------------------------------------------------------------
 [ ] Install LLVM-23.1.0-win64.exe (from github.com/llvm/llvm-project/releases,
     tag llvmorg-23.1.0). Default install folder:  C:\Program Files\LLVM
 [ ] Confirm the source is really 23.1.0:
         "C:\Program Files\LLVM\bin\clang.exe" --version
     Expected first line:  clang version 23.1.0
 [ ] Start from an EMPTY  <dev-repo>\toolchain\  folder.
     Do not keep or mix any file from the old LLVM 21 toolchain.
 [ ] Keep the folder structure EXACTLY as listed. clang finds its own
     headers and runtime libraries relative to bin\clang.exe
     (bin\..\lib\clang\23\...). Moving or renaming folders breaks it.

 SOURCE      = C:\Program Files\LLVM
 DESTINATION = <dev-repo>\toolchain

------------------------------------------------------------------------------
 1. bin\   (copy each file from SOURCE\bin\ to DESTINATION\bin\)
------------------------------------------------------------------------------
 Build tools
 [ ] bin\clang.exe              C compiler driver
 [ ] bin\clang++.exe            C++ compiler driver (identical copy of clang.exe)
                                Space saver (optional, ~100 MB): instead of
                                copying, run inside DESTINATION\bin:
                                    mklink /H clang++.exe clang.exe
 [ ] bin\lld-link.exe           linker (multithreaded)
 [ ] bin\llvm-ar.exe            static library tool (builds third-party .lib)
 [ ] bin\llvm-rc.exe            Windows resource compiler (icons, version info)
 [ ] bin\llvm-mt.exe            manifest tool (UTF-8 code page, long paths)

 Runtime
 [ ] bin\libomp.dll             OpenMP runtime: needed to RUN any program built
                                with -fopenmp (keep it next to nc.exe)

 Testing and diagnosis tools (development only)
 [ ] bin\llvm-symbolizer.exe    readable stack traces for AddressSanitizer
 [ ] bin\llvm-profdata.exe      merges .profraw files (PGO and coverage)
 [ ] bin\llvm-cov.exe           code-coverage reports
 [ ] bin\llvm-objdump.exe       disassembler
 [ ] bin\llvm-nm.exe            lists symbols (undefined-symbol link errors)
 [ ] bin\llvm-readobj.exe       DLL imports/exports of .exe/.dll files

------------------------------------------------------------------------------
 2. lib\   (top level)
------------------------------------------------------------------------------
 [ ] lib\libomp.lib             linked automatically by -fopenmp

 7. CHECKS AFTER COPYING  (run from <dev-repo>)
------------------------------------------------------------------------------
 [ ] toolchain\bin\clang.exe --version
       -> clang version 23.1.0, Target: x86_64-pc-windows-msvc
 [ ] toolchain\bin\clang.exe -print-resource-dir
       -> must end in  toolchain\lib\clang\23
 [ ] OpenMP test:
       toolchain\bin\clang++.exe -O2 -fopenmp -fuse-ld=lld test_omp.cpp -o test_omp.exe
       (copy toolchain\bin\libomp.dll next to test_omp.exe, then run it)
 [ ] AddressSanitizer test:
       toolchain\bin\clang++.exe -g -fsanitize=address -fuse-ld=lld test.cpp -o test_asan.exe
       (copy clang_rt.asan_dynamic-x86_64.dll next to test_asan.exe;
        add toolchain\bin to PATH so llvm-symbolizer is found)
 [ ] Measure the folder size (PowerShell):
       (Get-ChildItem -Recurse toolchain | Measure-Object Length -Sum).Sum / 1MB

 When upgrading LLVM later (e.g. 23.1.x): replace the WHOLE toolchain folder
 from one installation in one go. Never mix files of two versions.
